# 隱身登錄頁的實例級外觀

隱身模式首次初始化設置時，為實例生成一套登錄頁組合，保存在 D1 的
`site_settings.stealth_mode.appearance` 中。已有隱身設置會在首次讀取時自動補齊。
重新部署、刷新頁面、登錄失敗或切換隱身開關不會重新生成組合；無需新增數據庫遷移。
併發初始化和舊設置升級以數據庫中的結果為準，避免多個請求各自顯示不同的頁面。

只組合非功能特徵：

| 模塊 | 變化 |
| --- | --- |
| 頁面容器 | 簡潔主區域、帶邊框區塊、獨立面板 |
| 標題 | 直接標題、分隔標題、帶內部文字容器的標題 |
| 字段排版 | 嵌套標籤、獨立標籤、顯式關聯標籤與反向佈局 |
| 提交區域 | 直接按鈕、靠右按鈕、頁腳按鈕 |
| 失敗提示 | 段落、區塊、輔助區域；都保留 `role="alert"` |
| 外觀 | 配色、系統字體、圓角、間距、寬度、上邊距 |
| 非功能標識 | 表單控件 ID、常見 CSS 類名、樣式規則順序 |
| 通用文案 | 標題、按鈕和失敗提示的普通登錄措辭 |

只輸出選中的模板，不向頁面嵌入整個模板庫、配置版本、模板序號或隨機種子。
頁面不包含腳本、品牌資源、遠程字體或第三方請求。所有模板保留顯式或嵌套的
字段標籤、自動填充、鍵盤提交、焦點標識及小屏適配。

賬號與密碼字段、長度限制、提交編碼、登錄路由、會話 Cookie、來源校驗、
CSP 和資源認證行為維持原有協議。錯誤賬號、錯誤密碼與封禁賬號在同一實例
返回同一種通用錯誤，模板選擇不依賴賬號、密碼或認證結果。

這是減少固定頁面指紋的措施，並不保證無法歸一化識別，也不能保證誤封成本。
有限模板仍可以被枚舉；表單協議、HTTP 行為和服務基礎設施仍可能提供共同特徵。
修改功能協議或認證流程不屬於這次外觀隨機化的範圍。
