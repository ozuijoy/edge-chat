1. 設計思路 (Design Concept)

液態玻璃（Liquid Glass）是蘋果在 iOS 26 中引入的下一代 UI 語言。它不再是死板的模糊，而是具備物理特性的光學模擬。

  • 物理折射： 利用 SVG 噪點濾鏡對背景像素進行位移映射，模擬光線穿過流體時的扭曲感。
  • 多層解耦： 區分濾鏡層（扭曲）、遮罩層（色調）、高光層（反射）和內容層（清晰文字）。
  • 動態交互： 監聽鼠標或陀螺儀數據，實時更新鏡面高光位置，強化玻璃的物理存在感。

3. 餵給 AI 的提示詞 (AI Prompt)

複製以下內容發送給 AI（如 Claude 或 GPT），即可讓其生成符合該風格的組件：

"請幫我實現一個基於'液態玻璃 (Liquid Glass)'風格的 UI。要求：1. 使用 HTML/CSS 分層結構（filter, overlay, specular, content）。2. 必須包含一個 SVG 濾鏡，利用 feTurbulence 和 feDisplacementMap 實現背景的物理折射扭曲效果。3. 使用 JS 實現跟隨鼠標位置的動態 radial-gradient 高光。4. 整體視覺要有極高的通透感和深度感。"

4. 完整源代碼 (Full Source Code)

以下是實現該效果的核心代碼塊，包含關鍵的 CSS 變量和 SVG 濾鏡定義：


/* 核心 CSS 邏輯 */
.glass-container {
    filter: url(#liquid-refraction); /* 引用 SVG 濾鏡 */
    backdrop-filter: blur(15px);
}

.specular-layer {
    background: radial-gradient(circle at var(--x) var(--y), white, transparent);
}

/* SVG 濾鏡定義 */
<filter id="liquid-refraction">
    <feTurbulence baseFrequency="0.01" numOctaves="2" />
    <feDisplacementMap scale="40" />
</filter>
